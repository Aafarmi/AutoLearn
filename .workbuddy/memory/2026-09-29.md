### 读题失败的最终根因（有原文证据）

用户贴出原始响应，确认**不是字段错位，是 token 预算被推理吃光**：

```json
"message": {"content": "", "reasoning_content": "Let me analyze this screenshot carefully... Questi..."}
```

`deepseek/deepseek-v4.1-flash`（推理模型）把 `reasoning_content`（思维链）写到截断，
`content`（最终 JSON）一个 token 都没剩下 → `read_parse_failed` 且「前 400 字」为空。
提示词是生效的（模型认出了「作业2 CSS」「交卷」「15/44题」）。

修法：**调大 token 预算**（`solve/reader.py`）：`READ_MAX_TOKENS` 6144→16384、
`ADVANCE_MAX_TOKENS` 512→1024、`START_MAX_TOKENS` 512→2048。
`_extract_text` 的 `reasoning_content` 兜底仍保留（别的厂商可能把最终答案放那里），
但对本场景真正起作用的是给足预算。**用推理模型做视觉读题，max_tokens 不能省。**
