# 技能：判断题（`true_false`）

## 适用范围

只用于视觉组已判定为**判断题**并传入 `skill_id=true_false` 的题目。它判断一道陈述是否成立；不适用于单项选择、多选、填空或简答题。

## 作答映射

判断题页面通常以两个选项呈现（如「正确 / 错误」「对 / 错」「是 / 否」）。先根据题干所给条件判断陈述真假，再把结论映射到输入中与之对应的**页面标号**：

- 陈述成立 → 选择表示正确/对/是的选项。
- 陈述不成立 → 选择表示错误/错/否的选项。

不得假定页面标号一定是 A/B，也不得靠位置猜映射；按视觉组传入的选项文字与标号配对。页面如果没有可辨认的正/反两项、题干不是一个可判真假的陈述，或映射有歧义，返回空数组并说明原因。

## 判断步骤

1. 将命题拆成关键主张、量词、条件、否定、时间/范围限定。保留「所有」「存在」「必然」「可能」「不」「仅当」等限定词。
2. 按题目给出的条件核验命题；使用反例即可推翻全称命题，使用已知条件或定义判断必要关系。
3. 只在结论明确时映射至页面上的「正确/错误」对应选项。
4. 若题面缺失、出现 `$?$`、条件不足、陈述有歧义或不能确认选项映射，输出 `chosen_labels: []`、`confidence: 0`，不蒙猜。

## 输出

严格遵循解题组共享 JSON 契约：`chosen_labels` 只放一个页面标号；`confidence` 为 0 到 1；`reason` 用一句话说明命题依据与映射。无法作答时空数组、置信度 0。

## 禁止事项

- 不将「判断题」按普通单选的知识题模板作答；必须执行「判命题真假 → 映射正/反选项」这两步。
- 不假定「A=正确、B=错误」；标号由页面决定。
- 不因句子听起来熟悉就忽略量词、否定、前提与边界条件。
- 不改视觉组传入的题型，也不查看图像、截图或坐标。

## 简短示例

输入陈述为「所有素数都是奇数」，页面有 `A. 正确`、`B. 错误`。检查反例 2 后，判命题为假，选择与「错误」配对的页面标号 `B`。这里的标号仅属于示例；实际题目必须按传入的标号与选项文字映射。
