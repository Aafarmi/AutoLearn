# 推进技能：点控件进下一题（`advance_click`）

## 适用范围

只用于「画面上有一个**固定**的推进控件，点它就从当前题走到下一题」的页面。它属于**推进技能**，不绑任何题型：同一道单选题、判断题都能用它推进；也不能拿它代替题型技能（`single_choice` / `true_false`）。

## 什么时候选它

- 画面上有一个明确的「下一题 / 下一页 / 继续 / 保存并下一题 / 下一题（→）」控件；
- 它**紧挨着当前这一道题**，或在页脚固定出现，点它就是切换到下一题；
- 页面上**没有**题号答题卡（有答题卡时优先 `advance_card`：点题号是最确定的落点）。

## 要给出的观测

选它时，`page` 里必须有这三样，且**都按当前这一屏重新量**：

| 字段 | 内容 |
|---|---|
| `advance_skill_id` | 固定写 `"advance_click"` |
| `page.next_control.box` | 这个控件本身的归一化框 `[x, y, 宽, 高]`，紧贴按钮边框 |
| `page.next_control.label` | 控件上的字（如 `"下一题"`） |

执行层点的是 **`next_control.box` 的中心**，所以框必须紧贴控件本身：框拉到整条页脚（含两侧空白）时，中心会落在空白上，等于没点。

## 判定步骤

1. 先在**本屏**找到那个控件，读出它的文字，确认它管的是「进下一题」而不是「交卷 / 提交」—— 交卷类按钮写在 `page.submit`，**不要**写进 `next_control`。
2. 用本屏的画面量它的框（不要回忆上一屏的位置）。
3. 给出 `advance_skill_id: "advance_click"`。
4. 点完之后的下一屏**重新走一遍这个判断**：控件可能换了位置、文字甚至消失。

## 禁止事项

- 不沿用上一屏的坐标：页面滚动、答题卡展开、提示条弹出都会让控件移位。
- 不把「提交 / 交卷 / 确定提交」当成 `next_control` —— 那是 `page.submit`。
- 看不到控件时**不要**编一个框，也不要因为「上一屏有」就继续报：改报 `advance_swipe`（题目同屏）或省略 `advance_skill_id`。
- 不改题型、不给答案、不写解释性散文。

## 简短示例

```json
{
  "page": {
    "current": 7,
    "advance_skill_id": "advance_click",
    "next_control": {"box": [0.855, 0.935, 0.115, 0.048], "label": "下一题"},
    "completed": "not_done"
  },
  "questions": []
}
```

示例里的框只属于这一屏；下一屏必须重新量。
