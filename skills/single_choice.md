# 技能：单项选择题（`single_choice`）

## 适用范围

只用于视觉组已判定为**单项选择题**并传入 `skill_id=single_choice` 的题目。题目应有页面可见的候选选项。该技能不适用于多选、判断、填空或简答题。

## 作答步骤

1. 逐字理解题干与每个选项，保留否定词、范围词、数字、单位及公式，不补写题面没有的信息。
2. 抽取题干要求：要选正确项还是错误项、对象与条件是什么。
3. 独立判断候选项的真假/符合程度；需要计算时验算，并检查是否只有一个选项满足题意。
4. 将答案映射回输入中的**页面标号**，只给一个标号。不得重排、重编号或根据选项位置推算新标号。
5. 若题面缺失、选项不全、出现 `$?$`、题干含义无法确定、没有唯一候选，返回空数组与 `confidence: 0`，说明原因；不猜。

## 输出

仍严格遵循解题组共享 JSON 契约：`chosen_labels` 恰好一个页面标号；`confidence` 为 0 到 1；`reason` 用一句话概括判断依据。无法作答时 `chosen_labels: []`、`confidence: 0`。

## 禁止事项

- 不改变题型；不把单选题变成多选题。
- 不输出技能库以外的字段；不请求或使用截图、坐标。
- 不因为题目常见或熟悉而补全题面。
- 发现视觉判型与题面明显矛盾时，空作答并说明冲突，不自行改判。

## 简短示例

输入：题干「下列说法正确的是？」；页面选项标号为 `A`、`C`、`D`。
只判断并输出唯一正确的**原页面标号**，例如 `{"chosen_labels":["C"],"confidence":0.9,"reason":"只有 C 符合题干条件。"}`。示例不预设具体题目的答案。
